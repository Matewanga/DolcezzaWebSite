## 🎀 **Sobre o Projeto**
**Dolcezza** é um website desenvolvido em **React e Node.Js**, pensado para trazer uma experiência encantadora para quem ama doces artesanais.  
Com uma interface suave, acolhedora e inspirada nas cores da confeitaria, o website permite navegar entre produtos, conhecer detalhes das receitas e fazer pedidos de forma simples e elegante.

Nosso foco é criar uma experiência onde cada toque na tela tenha a mesma delicadeza de um confeiteiro colocando o toque final em um doce.

---

## 🍬 **Objetivo Geral**
Proporcionar uma plataforma moderna que conecte apaixonados por doces a confeiteiros artesanais, valorizando cada detalhe: o sabor, a estética e o carinho por trás de cada criação.
